## Project

Moamo — a Flutter app (Android/iOS) for gathering around books ("책으로 모이고, 이야기로 이어지는 곳"). Flutter SDK 3.47.5 (pinned in `.fvmrc`), Dart `^3.12.2`.

Status: all screens exist. Wired to the backend (Riverpod + generated API client): Kakao login/auto-login, library home, bookshelves (create/edit/decorate/books), book search/detail/memos, guestbook. Community, My page (items, random draw), notifications and certification still use hard-coded data (`// TODO: 서버 데이터로 교체`) because the backend has no APIs for them yet. ## Architecture

- `lib/main.dart` — entry point. Calls `FlutterNativeSplash.preserve()`; the native splash stays up until `FlutterNativeSplash.remove()` is called in `SplashScreen`.
- `lib/app/` — app-wide wiring only: `Moamo` root widget (`MaterialApp.router`), `AppTheme`, `MainShell` (bottom navigation), and the single `GoRouter` in `router.dart` (initial route `/splash`). Tab screens live in a `StatefulShellRoute.indexedStack`; full-screen routes (notifications, guestbook, decorate, etc.) sit at the top level. Each screen exposes its path as a static `url`.
- `lib/features/<feature>/` — one folder per feature (`auth`, `library`, `bookcase_*`, `book_search`, `book_detail`, `guestbook`, `community`, `certification`, `my`, `notification`, `splash`, `navigation`). `ui/` holds screens (`<name>_screen.dart`) and `ui/widgets/`; `data/` or `model/` holds Riverpod providers (`@riverpod` codegen).
- `lib/shared/api/` — API client generated by swagger_parser from `openapi.json` (gitignored; never edit by hand).
- `lib/shared/network/api_client.dart` — Dio setup, base URL, bearer token, and one-time retry on 401 via token refresh. The backend runs on Render and can take 40s+ on a cold start (60s timeout).
- `lib/shared/theme/`, `lib/shared/dimension/` — design tokens as `abstract final class` with `static const` members: `AppColors`, `AppTextStyles`, `AppRadius`, `AppIconSizes`, `AppBaseSizes`. Use these instead of hard-coded colors, font sizes, or spacing. Text styles apply letter spacing as `fontSize * -0.01`.
- `lib/shared/widget/` — reusable widgets (`AppButton`, `AppChip`, `AppDialog`, `AppToast`, `SearchField`, `SvgIcon`, `BookInfoTile`).

## Splash screen

Two stages, because the Android 12+ native splash API can't render the design (it crops the center image to a circle and caps branding at ~200×80dp):

1. Native splash (`flutter_native_splash.yaml`) shows only the background color `#213448` (`AppColors.secondary100`). Android 12 uses `assets/images/transparent.png` so the launcher icon isn't shown.
2. `SplashScreen` (Flutter) draws the actual design (tagline, logo, bottom character image). It removes the native splash, tries auto-login with the stored Kakao token for at least 2 seconds, then goes to the library home or `/login`.

Files under `android/app/src/main/res/` and `ios/Runner/` related to launch screens are generated — edit the yaml and regenerate instead. iOS caches launch screens; delete the app to see changes.
